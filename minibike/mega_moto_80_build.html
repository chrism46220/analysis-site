Research sources: Mike's Mini Motors YouTube series (Part 1 & 2), GoPowerSports product catalog, user fitment reports. Status: Live working document — prices and exact fitment for some items require verification.

1. Adapter Plate Investigation

The GoPowerSports MMFAMPBENT ("Mega Moto 80 Adapter Plate, 196/212/225 Engines") is the go-to adapter plate for mounting a Predator 212cc engine into a Mega Moto 80 frame.

Claimed Fitment

  • SKU: MMFAMPBENT
  • Intended engines: Predator 212cc (and 196cc / 225cc variants)
  • Product explicitly marketed for the Mega Moto 80

User Fitment Failure Report

Despite the product description, one user reports this plate did not fit their installation.

Known / Suspected Causes

Cause Detail
Bolt pattern mismatch The plate's mounting holes may not perfectly align with the MM80 frame's engine mounting holes.
Frame production variation Mega Moto 80 frames vary between production runs — bolt hole positions can shift slightly.
Sprocket alignment interference The crankcase may collide with the chassis when centering the clutch sprocket with the rear sprocket.
Slotting required Some builds succeed only after slotting or drilling the plate's mounting holes to match the frame pattern.

Recommended Approach

  1. Attempt dry-fit the MMFAMPBENT plate before any permanent installation.
  2. If holes do not align, slot the plate holes with a round file or drill — do not modify the frame.
  3. Verify clutch-to-rear-sprocket chain alignment before final install. Shim or adjust as needed.
  4. Alternative: If the plate is unusable, a flat steel plate can be fabricated locally using the MM80 frame hole pattern as a template.

MMFAMPBENT verdict: Likely fit — but confirmed user fitment failure; may require modification.

5. Assembly Instructions

Overview

This procedure covers swapping a Predator 212cc engine into a Mega Moto 80 frame using the GoPowerSports adapter plate and associated parts.

Tools Required

  • Socket set (metric and SAE)
  • Torque wrench (in-lb range for small fasteners)
  • Allen key set
  • Round file or drill (for slotting adapter plate holes if needed)
  • Chain breaker / rivet tool (for #35 chain)
  • Screwdrivers (flathead and Phillips)
  • Pliers
  • Feeler gauge (for valve lash check — optional but recommended)

Step 1 — Prepare the Frame

  1. Remove the old engine (if present) and clean the engine mounting area of the frame.
  2. Inspect the MM80 frame for cracks, bends, or rust around the mounting plate area.
  3. Remove any old gaskets, threadlocker residue, or debris from the bolt holes.

Step 2 — Prepare the Adapter Plate (MMFAMPBENT)

  1. Place the GoPowerSports adapter plate onto the MM80 frame mounting surface.
  2. Insert the frame's mounting bolts through the plate holes.
  3. Fitment check: If bolts will not pass through, mark the obstructed areas on the plate.
  4. Remove the plate and slot the offending holes using a round file (preferred) or drill with a sharp bit. Enlarge just enough for bolt passage — do not remove excessive material.
  5. Deburr the slot edges.
  6. Dry-fit again after slotting. Confirm all bolts seat flush and the plate sits flat.

If the plate is completely unusable: fabricate a flat steel adapter using the frame hole pattern as a template. Use 3/16" or 1/4" mild steel.

Step 3 — Prepare the Engine

  1. Remove the Predator 212 from its crate. Drain shipping oil and fill with 0.6 qt SAE 10W-30.
  2. (Optional but recommended) Check valve lash: intake 0.003", exhaust 0.005".
  3. Remove the stock muffler and air filter assembly — these will be replaced.
  4. Install the GoPowerSports header and muffler onto the engine. Torque to manufacturer spec.
  5. Install the low-profile air intake kit. Ensure no gasket gaps.
  6. Install the throttle linkage kit onto the carburetor. Verify cable motion is smooth through full range.

Step 4 — Mount the Engine to the Frame

  1. Bolt the adapter plate to the Predator 212 crankcase using the provided bolts. Use Loctite 242 (blue) on every bolt.
  2. Lower the engine + plate assembly onto the MM80 frame.
  3. Insert frame mounting bolts through the plate.
  4. Finger-tighten all bolts.
  5. Sprocket alignment check: Place the clutch on the engine output shaft. Run a straightedge along the clutch sprocket face toward the rear sprocket. They must be aligned within ~1/8".
  6. If misaligned, reposition the engine on the plate (slotting may help) or shim the clutch.
  7. Once aligned, torque all bolts to spec. Apply Loctite to frame-to-plate bolts as well.

Step 5 — Install Clutch and Chain

  1. Install the #35 clutch onto the engine output shaft. Tighten setscrew(s) with Loctite.
  2. Install the #35 chain onto the clutch sprocket and rear sprocket.
  3. Cut chain to length using chain breaker. Install master link.
  4. Adjust chain tension: ~1/2" of up/down play at mid-span.
  5. If using a chain tensioner, install it on the slack (return) side of the chain.

Step 6 — Throttle and Controls

  1. Route the throttle cable from the handlebar twist grip to the Predator 212 carburetor.
  2. Secure cable using zip ties along the frame. Avoid sharp bends or contact with the exhaust.
  3. Adjust cable barrel adjuster so the carb slide opens fully when the throttle is twisted, and returns to idle when released.
  4. Verify kill switch wiring (if retaining stock kill switch). Predator 212 has a low-oil shutoff — this must be wired to a kill switch or left operational.

Step 7 — Fuel

  1. Install the stock Predator 212 fuel tank onto the engine.
  2. Verify frame crossbar clearance. If the tank contacts the crossbar, consider a low-profile tank or notch/cushion the contact area.
  3. Connect the fuel line from tank to carburetor.
  4. Install vent line (if present on the tank).

Step 8 — Final Checks

Check Detail
All bolts torqued and Loctited Engine-to-plate, plate-to-frame, clutch setscrew, exhaust bolts
Chain tension and alignment ~1/2" play, sprockets aligned
Throttle action Full open, full return, no binding
Kill switch operation Engine shuts off when activated
Fuel system No leaks at tank, line, or carb
Clearances No contact between exhaust / intake / clutch / frame
Oil level Correct fill, no leaks
Clutch cover installed (if using) Bolts flush, no binding

Step 9 — First Start (Break-In)

  1. Choke on, fuel valve open. Pull start. No more than 3-4 pulls; if no start, check fuel flow and spark.
  2. Let engine idle for 30 seconds, then blip throttle.
  3. Ride gently for the first 15-20 minutes. Vary engine speed but avoid sustained WOT.
  4. After break-in period, change oil.
  5. Re-torque all mounting and exhaust bolts after the first heat cycle.
