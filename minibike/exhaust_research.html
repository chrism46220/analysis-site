Exhaust Research — Mega Moto 80 + Predator 212

Evidence-based takeaway

For a rearward-exit, under-seat-preferred, kid-safer Mega Moto 80 / Predator 212 build with a centrifugal clutch, the strongest matches from the researched GoPowerSports parts are:

  1. Header Pipe, 3 Stage Center Exit 196/212, Chrome — best match on paper for a rearward-centered route.
  2. Header Pipe, Drag Low Center Exit 196/212, Chrome — promising for a tucked low/rearward route if frame and ground clearance work.
  3. Exhaust Silencer, 1-5/16" with HD SS Clamp + RLV Muffler Clamp — best add-ons for noise reduction and safer final setup.

The 3 Stage Side Exit and Trumpet headers look less aligned with the goal because they leave more exposed side pipe near the rider’s leg unless heavily wrapped/shielded.

Build evidence found

  • Mike’s Mini Motors Mega Moto build page includes a Mega Moto 80 / Predator 212 build playlist and links a GoPowerSports muffler kit plus header wrap in the parts list:
    Evidence URL: https://www.mikesminimotors.com/builds/mega-moto-mini-bike/
  • That same build page includes a video titled “Mega Moto Mini Bike - RLV Muffler Install and Sound Comparison”, which is direct evidence that an RLV/B91-style muffler solution was used on a Mega Moto build:
    Evidence URL: https://www.youtube.com/watch?v=HdduqH7Js2k

Product findings

1) Header Pipe, Trumpet 196/212/225

  • SKU: KDPRED65HP
  • Price: $32.95
  • Link: https://www.gopowersports.com/header-pipe-trumpet-196-212-225/
  • Evidence URL: https://www.gopowersports.com/header-pipe-trumpet-196-212-225/
  • Fitment notes: GoPowerSports lists it for 196cc / 212cc / 225cc engines, so Predator 212 compatibility is supported at the engine level. I found no Mega Moto 80-specific install evidence for this exact header.
  • Routing description: Product image shows a curved header that exits outward/upward to the side rather than straight rearward. Cheapest option, but not the best fit for an under-seat child-safer layout without extra shielding/wrap.

2) Header Pipe, 3 Stage Side Exit 196/212

  • SKU: GPS-0010
  • Price: $39.95
  • Link: https://www.gopowersports.com/header-pipe-3-stage-side-exit-196-212/
  • Evidence URL: https://www.gopowersports.com/header-pipe-3-stage-side-exit-196-212/
  • Fitment notes: GoPowerSports says the side exit design ensures maximum clearance and is a direct-fit 196/212 header. Good engine-level fit for Predator 212, but I found no direct MM80 proof for this exact part.
  • Routing description: Clearly a side-exit header. It appears to sweep out and upward to the side, which helps packaging but leaves more hot pipe exposed near the rider’s leg. Less desirable for kids unless paired with muffler, wrap, and/or shielding.

3) Header Pipe, 3 Stage Center Exit 196/212, Chrome

  • SKU: GPS-0020-CR
  • Price: $139.95
  • Link: https://www.gopowersports.com/header-pipe-3-stage-center-exit-196cc-212cc-chrome/
  • Evidence URL: https://www.gopowersports.com/header-pipe-3-stage-center-exit-196cc-212cc-chrome/
  • Fitment notes: GoPowerSports lists it as a 196/212 center-exit header. Of the researched headers, this is the best paper match for a Mega Moto 80 build aiming for a rearward route with a centrifugal clutch because it is not designed around a side-exit layout. MM80-specific clearance still needs final verification.
  • Routing description: Product labeling and image indicate a center/rearward-style exit with a longer run than the side-exit pipe. This is the closest match to an under-seat/tucked rearward concept.

4) Exhaust Silencer, 1-5/16" with HD SS Clamp

  • SKU: B91XL
  • Price: $54.95
  • Link: https://www.gopowersports.com/exhaust-silencer-1-5-16-with-hd-ss-clamp/
  • Evidence URL: https://www.gopowersports.com/exhaust-silencer-1-5-16-with-hd-ss-clamp/
  • Additional evidence URL: https://www.youtube.com/watch?v=HdduqH7Js2k
  • Fitment notes: GoPowerSports describes it as a 1-5/16" exhaust silencer for small-engine applications. Mike’s Mini Motors has a Mega Moto video specifically showing an RLV muffler install, so an RLV/B91-style muffler setup has real Mega Moto build precedent.
  • Routing description: This is a muffler/silencer add-on, not a header by itself. Best used at the outlet of a compatible header to cut noise and reduce burn risk from an open pipe end.

5) Header Pipe, Drag Low Center Exit 196/212, Chrome

  • SKU: EXF5050-CR
  • Price: $153.95
  • Link: https://www.gopowersports.com/header-pipe-drag-low-center-exit-196-212-chrome/
  • Evidence URL: https://www.gopowersports.com/header-pipe-drag-low-center-exit-196-212-chrome/
  • Fitment notes: GoPowerSports describes it as a low center exit header for 196/212 engines. This makes it a strong candidate where you want a low, tucked, rearward path and are running a centrifugal clutch instead of a torque converter. Main open question is frame/ground/chain clearance on the MM80 specifically.
  • Routing description: Designed as a low center-exit pipe. Compared with side-exit headers, it looks more promising for a tucked rearward route and for keeping the hottest pipe closer to the bike centerline.

6) RLV Muffler Clamp

  • SKU: 364144
  • Price: $8.75
  • Link: https://www.gopowersports.com/rlv-muffler-clamp/
  • Evidence URL: https://www.gopowersports.com/rlv-muffler-clamp/
  • Additional evidence URL: https://www.youtube.com/watch?v=HdduqH7Js2k
  • Fitment notes: Accessory part for securing an RLV-style muffler/silencer. Relevant because Mike’s Mini Motors documents an RLV muffler install on a Mega Moto build.
  • Routing description: Not a routing part by itself; it is the mounting hardware that makes an RLV/B91 muffler setup practical and secure.

Best-fit conclusion for this build

If the goal is rearward exit, under-seat preference, kid-safer packaging, and centrifugal-clutch compatibility, the most sensible order to investigate is:

  1. GPS-0020-CR + B91XL + 364144
  2. EXF5050-CR + B91XL + 364144
  3. GPS-0010 only if budget matters and you’re willing to add wrap/shielding

Gaps / caution

I found strong engine-level product evidence and good Mega Moto muffler-install evidence from Mike’s Mini Motors, but not a clean forum/photo confirmation showing these exact GoPowerSports headers installed on a Mega Moto 80 with a Predator 212 and centrifugal clutch. Final choice should still be checked against: - seat pan clearance - rear tire clearance - leg/burn exposure - chain/clutch cover clearance - whether a heat shield or wrap will be added
